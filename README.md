# 🍳 CookDish — Interactive Culinary & Meal Planning App

**CookDish** is a modern, responsive, full-stack web application designed to help users discover, plan, and cook authentic Nigerian delicacies and international recipes. Featuring an interactive step-by-step **Cooking Mode**, a built-in step timer, meal planning, smart shopping lists, and multi-source API recipe search.

---

## ✨ Features

- 🇳🇬 **Authentic Nigerian & Cultural Cuisine**: Accurate traditional recipes including **Authentic Egusi Soup**, **Traditional Igbo Oha Soup**, **Ogbono Draw Soup**, **Okra Soup**, **Smoky Party Jollof Rice**, **Ofada Rice**, **Beef Suya**, **Asun**, **Chin Chin**, and **Nigerian Meat Pie**.
- ⏱️ **Interactive Immersive Cooking Mode**: Step-by-step full-screen cooking assistant with an active step countdown timer, chef's tips, and 0ms instant touch controls.
- 🔍 **Multi-Source Recipe Aggregator**: Concurrently fetches and merges recipes from **TheMealDB**, **Spoonacular**, **Edamam**, **DummyJSON**, and curated local Nigerian dishes.
- 📱 **100% Cross-Device Responsive**: Pixel-perfect UI tuned across mobile phones (`<640px`), tablets (`640px-1024px`), laptops (`1024px-1280px`), and desktop monitors (`>1280px`).
- 🛒 **Meal Planner & Shopping List**: Organize weekly meal slots and automatically aggregate ingredients into a interactive shopping checklist.

## 🚀 Getting Started

### Prerequisites

- Node.js `18.x` or later
- `npm`, `pnpm`, or `yarn`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/cookdish-recipe-app.git
   cd cookdish-recipe-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

---

## 🌐 Deploying to Vercel

The easiest way to deploy CookDish is using [Vercel](https://vercel.com):

1. Push code to your GitHub repository.
2. Import repository on [Vercel](https://vercel.com/new).
3. Click **Deploy**.
